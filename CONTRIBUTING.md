# Contribuir

## Preparar el proyecto

1. Clona el repositorio.
2. Desde el directorio del proyecto, ejecuta `npm install` si necesitas instalar dependencias.
3. Inicia el servidor local con `npm run dev` y abre http://localhost:8000.

## Proponer cambios

1. Crea una rama descriptiva a partir de `main`.
2. Haz cambios pequeños y explica claramente su objetivo.
3. Si actualizas datos o contenidos, incluye las fuentes y la fecha de consulta.
4. Comprueba el resultado en local.
5. Abre un pull request hacia `main` describiendo los cambios realizados.

Las contribuciones deben respetar la licencia del proyecto y no incluir credenciales, datos privados ni material sin permiso de reutilización.
